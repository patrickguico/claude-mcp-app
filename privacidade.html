Política de privacidade

Última atualização: 24 de novembro de 2026.

Quem usa

O aplicativo "MCP Analytics Patrick" é de uso pessoal do seu próprio dono. Ninguém mais faz login nele.

Quais dados acessa

Com a autorização do dono, o aplicativo lê, somente para leitura, relatórios do Google Analytics e do Google Ads das contas a que o dono já tem acesso.

Como os dados são usados

Os dados são consultados sob demanda, no computador do dono, para análise de desempenho. Não são vendidos, não são compartilhados com terceiros e não são usados para publicidade.

Armazenamento

A credencial de acesso fica apenas no computador do dono. O aplicativo não mantém banco de dados próprio.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Dados do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
